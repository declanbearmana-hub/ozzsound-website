# Ozzsound Website

Development website for Ozzsound Mobile Music.

## Where to add media
- `assets/images/weddings/`
- `assets/images/parties/`
- `assets/images/kids/`
- `assets/images/corporate/`
- `assets/images/sporting/`
- `assets/images/general/`
- `assets/videos/`

## Hero background video
Put a short, compressed MP4 at `assets/videos/hero-background.mp4`. The site automatically tries to load it. If it is missing, the animated dark gradient background is used instead.

## Contact details
Edit `config/site-config.js` when the new phone, email and social accounts are ready. Blank values are intentionally not shown publicly.

## Preview locally
Double-click `index.html`. For video and full browser testing, using a simple local web server is recommended.
